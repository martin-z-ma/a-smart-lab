# Important publishing steps

1. In the GitHub repository, delete the old `index.md` file. It conflicts with the new `index.html` homepage.
2. Upload all files and folders from this package to the repository root, replacing files with the same names.
3. Make sure `index.html` shows a non-zero file size after upload.
4. Commit the changes to `main`.
5. Open **Actions** and wait until **pages build and deployment** shows a green check.
6. Open the website in a private/incognito window or hard-refresh it with `Ctrl+F5`.
